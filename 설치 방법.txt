마리나라 GM 전용 TRPG 1.1.10
==========================

Marinara Engine의 GM(게임) 모드에 "마리나라 GM 전용 TRPG"를 추가해요.
직접 키퍼를 맡고, AI가 조사자 한 명을 연기해요. 크툴루의 부름 7판 규칙과 호환돼요.
Marinara Engine 2.5.2 기준으로 만들었어요.

※ 기능 사용법과 처음 설정 순서는 같은 폴더의 "설명서.html"을 더블클릭해서 보세요.


■ 꼭 알아 두세요
- 팬이 만든 비공식 무료 확장이에요. 돈을 받고 팔거나 유료로 나눠 줄 수 없어요.
- Marinara Engine(Pasta-Devs)의 공식 기능이 아니에요.
- "크툴루의 부름(Call of Cthulhu)"은 Chaosium Inc.의 상표예요. 이 확장은 Chaosium과 관련이 없고,
  Chaosium의 허가나 보증을 받지 않았어요. 규칙서는 들어 있지 않으니 규칙서는 정식으로 구해 주세요.
- 권리자가 삭제를 요청하면 바로 내려요.


■ 준비물
- git으로 설치한 Marinara Engine (start.bat으로 실행하는 설치)
- Node.js, git (Marinara를 설치할 때 함께 깔려 있어요)


■ 설치
1. Marinara를 꺼 주세요.
2. 이 폴더(marinara-gm-trpg)를 통째로 Marinara-Engine 폴더 안에 넣어 주세요.
     Marinara-Engine\
       ├ start.bat
       ├ packages\
       └ marinara-gm-trpg\   ← 여기
3. 폴더 안의 "설치.bat"을 더블클릭하세요.
   파일 복사 → 보호 등록 → Marinara 연결 → 빌드 순서로 진행돼요. 1~2분 걸릴 수 있어요.
4. "[완료]"가 나오면 Marinara를 다시 켜세요.
5. 새 대화 → GM(게임) → "마리나라 GM 전용 TRPG"를 고르면 시작돼요.

예전 이름(CoC 7th TRPG)으로 설치해 두셨다면, 이 폴더의 "설치.bat"을 실행하면 그대로 새 판으로 바뀌어요.
게임 기록은 그대로 남아요.


■ Marinara를 업데이트한 뒤
Marinara 업데이트는 게임 연결 부분을 잠깐 빼 두었다가 다시 넣어요.
업데이트가 같은 줄을 바꾸면 다시 들어가지 않을 수 있어요.
→ 게임 메뉴가 안 보이거나 일반 게임 화면이 나오면 Marinara를 끄고 "다시 적용.bat"을 실행하세요.
   이미 들어가 있으면 그대로 두고, 빠진 부분만 다시 넣어요.
→ "이 Marinara 버전에는 게임 연결 부분이 맞지 않아요"가 나오면, Marinara가 크게 바뀐 거예요.
   이때는 아무것도 바꾸지 않고 원래대로 되돌려 두니, 새 버전의 패키지를 받아 주세요.


■ 제거
"제거.bat"을 실행하면 게임 파일과 연결 부분을 빼고 다시 빌드해요.
게임 기록(Marinara 데이터 폴더의 coc7-games)은 지우지 않아요.
빌드 호환 수정(타입 표기 4곳)은 빌드가 계속 되도록 남겨 둬요. 기능은 바뀌지 않아요.


■ 무엇이 바뀌나요
- 새로 추가되는 파일
    packages\client\src\components\game\coc7\  (게임 화면 전체)
    packages\server\src\routes\coc7-game.routes.ts, coc7-prices.ts  (게임 서버)
    ※ 파일 이름의 coc7은 예전 판과 게임 기록을 그대로 쓰기 위한 내부 이름이에요.
- Marinara 파일에 넣는 연결 부분 (patches\coc7-host.patch)
    새 대화 창의 게임 메뉴, 채팅 화면 연결, 서버 경로 등록, 삽화 처리
- 빌드 호환 수정 (patches\build-compat.patch, 맞을 때만)
    일부 환경에서 Marinara 빌드가 멈추는 타입 표기 4곳
- .git\info\exclude
    Marinara 실행기(start.bat)는 켤 때마다 새로 생긴 소스 파일을 지워요.
    게임 파일이 지워지지 않게 여기 등록해요.


■ 함께 쓰면 좋은 것 (없어도 돼요)
- 기억 서재 확장: 기억 서재 탭에서 이 게임 방의 기억을 켜고 정리할 수 있어요.
- 이미지 생성 연결: 삽화 기능에 써요.
  삽화 프롬프트를 쓰는 텍스트 모델은 세션·설정 → AI 조사자 설정 → "삽화 프롬프트 모델"에서 골라요.
  비워 두면 "별도 이미지 분석 모델"을, 그것도 없으면 Marinara 일러스트레이터/채팅/기본 연결을 써요.


■ 문제가 생기면
- 설치 창에 나온 [실패] 문구를 그대로 알려 주세요.
- 삽화가 "Gallery image prompt compilation failed: …"로 실패하면, ":" 뒤가 실제 이유예요.
  대개 삽화 프롬프트 모델 연결 문제(잔액, 서버 오류)라 다른 연결로 바꾸거나 다시 눌러 보세요.
- 바꾸지 않고 확인만 하려면, 이 폴더에서 명령 창을 열고 아래를 실행하세요.
    node install.mjs check
