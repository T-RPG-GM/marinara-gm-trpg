마리나라 GM 전용 TRPG 설명서

Marinara에서 혼자 즐기는 호러 조사 TRPG예요. 크툴루의 부름 7판 규칙과 호환돼요. 내가 키퍼가 되어 장면을 열고, AI가 조사자 한 명을 맡아 행동하고 말해요. 주사위와 시트, 기록은 화면이 알아서 챙겨요.

나 · 키퍼장면을 묘사하고 NPC를 연기하고 판정을 요청해요.
AI · 조사자시트대로 행동하고 대사하고, 필요하면 판정을 굴려요.
화면 · 기록관주사위, HP·SAN, 노트, 삽화, 기억을 정리해요.
꼭 알아 두세요
  • 비공식 · 무료 팬 프로젝트예요. Marinara Engine(Pasta-Devs)의 공식 기능이 아니에요.
  • 크툴루의 부름(Call of Cthulhu)은 Chaosium Inc.의 상표예요. 이 확장은 Chaosium과 관련이 없고, 허가나 보증을 받지 않았어요.
  • 규칙서 본문은 들어 있지 않아요. 플레이하려면 규칙서를 정식으로 구해 주세요.
  • 돈을 받고 팔거나 유료로 나눠 줄 수 없어요. 권리자가 삭제를 요청하면 바로 내려요.

처음 설정 순서

새 게임을 만든 뒤 위에서부터 차례로 하면 돼요. 선택 단계는 건너뛰어도 플레이할 수 있어요.

  1. 새 게임 만들기 필수

    새 대화를 누르고 GM(게임)에서 마리나라 GM 전용 TRPG를 고르면 게임 화면이 열려요.

  2. AI 조사자 연결 필수
    오른쪽 패널 → 세션·설정 → AI 조사자 설정
    • 조사자 봇카드 · AI가 연기할 캐릭터를 골라요. 카드의 설명이나 예시 대사가 외국어 대사 뒤에 괄호로 한국어 번역을 붙이는 식이면, AI도 대사를 그 형식으로 써요. 서술과 행동은 한국어예요.
    • 텍스트 모델 연결 · AI 답변에 쓸 모델이에요. 비워 두면 채팅 연결이나 기본 연결을 써요.
    • 프롬프트 프리셋 · 문체를 정하는 프리셋이에요. 비워 두면 채팅 프리셋을 따라요.
    • 별도 이미지 분석 모델 선택 · 핸드아웃 사진의 설명을 제안할 때 써요. 이미지를 볼 수 있는 모델이어야 해요.
    • 삽화 프롬프트 모델 선택 · 삽화용 태그를 쓰는 모델이에요. 비워 두면 이미지 분석 모델을 따라가요.

    다 고르면 연결 저장을 눌러요.

  3. 프리셋에서 보낼 부분 정하기 권장
    같은 화면, 프리셋 이름 아래

    자동으로 (문체만)이 기본이에요. 프리셋의 문체 부분과 {{기억}}만 보내고, 역할·상태창처럼 게임 규칙과 겹치는 부분은 빼요. 토큰이 크게 줄어요. 필요하면 부분을 직접 고르거나 전부 보내기를 눌러요.

  4. 조사자 로어북 고르기 선택
    같은 화면, 조사자 로어북

    AI 답변에 넣을 로어북을 골라요. 기본은 봇카드에 연결된 로어북이고, 봇카드 표시가 붙어 있어요. 다른 로어북을 체크하고 고른 로어북 저장을 누르면 고른 것만 써요. 모두 해제하고 저장하면 로어북을 보내지 않아요. 봇카드 로어북 쓰기를 누르면 기본으로 돌아가요.

    고른 로어북도 지금 장면에 나온 단어로 켜진 항목만 들어가요. Marinara에서 꺼 둔 로어북은 보내지 않아요.

  5. 내 페르소나 연결 선택
    세션·설정 → 플레이어 페르소나, 그다음 페르소나 시트 탭

    Marinara 페르소나를 고르고 페르소나 저장을 눌러요. 내 인물도 판정을 굴리게 하려면 페르소나 시트 탭에서 페르소나 시트 만들기를 눌러 시트를 만들어요. /check는 기본으로 이 시트로 굴려요.

  6. 조사자 시트 완성 필수
    조사자 시트 탭
    • 봇카드 불러오기 · 카드에 적힌 수치를 그대로 가져와요.
    • 능력치 자동 적용 AI 호출 · AI가 카드 내용을 보고 능력치, 직업, 관심 기능을 채워요. 직접 적어도 돼요.
    • 연령 보정 · 생성 확정 · 나이에 따른 보정과 포인트를 확인하고 생성 확정을 눌러요. 연령 보정을 안 하거나 기능점이 넘어도 확정돼요. 확정하면 캐릭터 시트 보기로 인쇄된 시트처럼 볼 수 있어요.
  7. 왼쪽 사진 정하기 선택
    조사자 시트 탭 → 조사자 프로필, 삽화 탭

    봇카드 사진이 기본으로 나와요. 다른 사진을 쓰려면 프로필 이미지를 올리고 이미지 적용을 눌러요. 보이는 부분은 삽화 탭의 왼쪽 사진 위치에서 가로·세로로 옮겨요.

  8. 게임 규칙 정하기 권장
    세션·설정 → 게임 설정
    • 키퍼 입력 후 자동 응답 · 켜면 내가 보낼 때마다 AI가 바로 답해요.
    • 판정 방식 · 자동, 승인 후, 직접, 비공개 중에서 골라요. 판정과 주사위에서 자세히 설명해요.
    • 행운 소비 허용 · 실패한 판정을 행운으로 바꾸는 선택 규칙이에요.
    • 응답 모델에 공개 이미지 첨부 · 모델이 이미지를 볼 수 있을 때만 켜요.
  9. 기억 서재 켜기 선택
    기억 서재 탭 → 이 게임 방을 기억 서재로

    기억 서재 확장이 있으면 켜 두세요. AI 답변마다 이어서 정리도 켜 두면 따로 신경 쓸 일이 없어요. 프리셋에 {{기억}}이 있어야 정리한 기억이 들어가요.

  10. 첫 장면 열기

    입력창에 /desc 비 내리는 아컴의 골목. 낡은 서점 문이 반쯤 열려 있다.처럼 장면을 쓰고 보낸 뒤 AI 답변을 눌러요. 이제 조사자가 움직이기 시작해요.

화면 구성

넓은 화면에서는 세 칸으로 나뉘어요. 폰처럼 좁은 화면에서는 위쪽 패널 보기 / 채팅 보기 버튼으로 바꿔 봐요.

조사자 사진

조사자 사진과 HP·SAN이 보여요. 사진을 누르면 크게 볼 수 있어요.

오른쪽 경계선을 끌면 너비가 바뀌고, 두 번 누르면 원래대로 돌아가요.

채팅

비 내리는 아컴의 골목…
조사자: 서점 안을 살펴본다.
관찰력 45 → 23 · 어려운 성공
장면, 대사, 판정, 삽화가 순서대로 쌓여요. 맨 위에 토큰 사용량이 보여요.

캠페인 패널

시트, 노트, NPC, 삽화, 설정 같은 13개 탭이 있어요.

왼쪽 가장자리의 › 로 접고, ‹ 로 다시 펼쳐요.

사진 칸 너비와 패널을 접었는지는 브라우저가 기억해서, 새로고침해도 그대로예요.

폰에서는 읽기 위주로 바뀌어요. 제목은 한 줄로 줄고, 조사자 사진 줄과 삽화 버튼은 숨겨져요(삽화는 PC에서 만들어요). 글씨가 조금 커지고, 메시지 버튼(수정·북마크·삭제)은 메시지 오른쪽 아래 ⋯를 눌러야 나와요. 입력창은 ✎ 입력하기 한 줄로 접혀 있다가 누르면 펼쳐지고, 접기로 다시 접어요. 오른쪽 끝 ⌄를 누르면 입력창이 아예 숨고 오른쪽 아래에 ✎ 동그라미만 남아요. ✎를 누르면 다시 나와요. 숨긴 상태는 새로고침해도 그대로예요. 패널 탭은 한 줄로 나와서 옆으로 밀어 골라요.

입력 명령어

입력창에 그냥 쓰면 키퍼의 말이 되고, 앞에 명령어를 붙이면 역할이 바뀌어요.

명령어하는 일예시

/em행동 묘사. 페르소나를 연결했으면 페르소나의 행동이 돼요./em 조심스럽게 손전등을 켠다.
*행동* "대사"페르소나 대사에서 별표로 감싼 부분은 회색 행동 칸에, 나머지는 그 아래 대사로 나와요. 조사자 답변과 같은 모양이에요.*고개를 든다.* "누구세요?"

/w키퍼만 보는 메모. 키퍼 기록 탭에 남아요./w 3장에서 단서 공개 예정

@{…}시트 값 불러오기.@{관찰력}

이 목록은 매크로 탭의 명령어 사용법에서도 볼 수 있어요.

판정과 주사위

/check 기능명은 기본으로 내 페르소나 시트로 굴려요. 조사자 시트로 굴리려면 /check pc 기능명처럼 앞에 pc나 조사자 이름을 붙여요. 뒤에 |로 난이도와 보너스·페널티를 더할 수 있어요.

쓰는 법뜻
/check 관찰력일반 난이도. 기준치 이하면 성공.
/check 관찰력 | hard어려움. 기준치의 1/2 이하여야 성공.
/check 관찰력 | extreme극단. 기준치의 1/5 이하여야 성공.
/check 관찰력 | hard | 1보너스 주사위 1개. -1은 페널티 주사위이고, -2부터 2까지 써요.

대성공 01

극단적 성공 02–12

어려운 성공 13–30

일반 성공 31–60

실패 61–99

대실패 100

기준치가 50 미만이면 96부터 100까지 모두 대실패예요.

판정 방식

세션·설정 → 게임 설정에서 골라요.

  • 키퍼 요청 직후 자동 굴림 · 판정을 요청하면 바로 굴려요.
  • 키퍼 승인 후 굴림 · AI가 요청한 판정을 내가 허락해야 굴려요.
  • 키퍼가 직접 굴림 버튼 사용 · 대기 중인 주사위를 내가 눌러서 굴려요.
  • 키퍼 비공개 굴림 · 결과를 키퍼만 봐요.

행운과 강행

  • 행운 소비 · 설정에서 켜면, 실패한 판정을 행운을 써서 성공으로 바꿀 수 있어요. 대성공·대실패·강행 판정과 이성·행운 판정에는 쓸 수 없어요.
  • 강행 · 실패한 판정을 한 번 더 굴려요. 판정 카드에 "강행"이 표시돼요.
  • 키퍼 수정 · 키퍼가 결과를 고치면 카드에 표시가 남아요.

오른쪽 패널 탭

탭마다 들어 있는 항목을 하나씩 설명해요. 항목 이름은 화면에 보이는 그대로예요. 접었다 편 상자 상태는 기억돼요.

캐릭터

조사자 시트

AI가 연기하는 조사자의 모든 수치가 여기 있어요.

조사자 봇카드
봇카드 불러오기로 카드에 적힌 수치를 가져와요. 능력치 자동 적용은 AI가 카드를 읽고 능력치와 직업·관심 기능을 채워요. 이때 텍스트 모델을 한 번 불러요.
조사자 프로필
이름, 나이, 성별과 사진이에요. 사진을 올리면 왼쪽 사진이 바뀌고, 봇카드 사진으로 복원으로 되돌려요.
능력치와 자원
근력, 건강 같은 8개 능력치와 HP, MP, SAN, 행운이에요.
기능 목록
기능을 추가하고 기준치를 정해요. 성공한 기능에는 경험 체크가 남고, 성장 굴림으로 올릴 수 있어요.
연령 보정 · 생성 확정
나이에 따른 보정과 포인트를 확인하고 생성 확정을 눌러요. 연령 보정을 안 하거나 기능점이 넘어도 확정돼요. 확정 뒤에도 수정할 수 있어요.

보관

메시지 보관함

다시 보고 싶은 메시지를 모아 둬요.

북마크
메시지에서 북마크에 추가한 것들이 모여요. 메시지로 이동을 누르면 채팅의 그 자리로 가요.

삽화

고른 장면으로 그림을 그려 채팅에 붙여요. 이미지 생성 연결이 있어야 해요.

  1. 장면 고르기

    채팅 위쪽 삽화 도구에서 장면 선택을 켜고, 그림으로 만들 메시지를 골라요.

  2. 그리기

    그림 아이콘을 누르면 삽화 프롬프트 모델이 그림용 태그를 쓰고, 이미지 모델이 그려요.

  3. 확인하기

    삽화는 고른 마지막 메시지 아래에 붙어요. 누르면 크게 보이고 프롬프트도 볼 수 있어요.

그림 위 버튼

  • 다시 그리기 · 장면부터 프롬프트를 새로 써서 다시 그려요. 새 그림은 버전으로 쌓이고, 그림 위에 4/4처럼 지금 보이는 버전과 전체 버전 수가 나와요.
  • 숨기기 · 채팅에서만 안 보이게 해요. 파일은 남아요.
  • 크게 보기 · 프롬프트를 고쳐 이 프롬프트로 다시 그리기, 예전 버전으로 바꾸기, 왼쪽 사진으로 쓰기.
  • 완전 삭제 · 삽화 탭에서 해요. 모든 버전 파일까지 지워져요.

모습이 잘 나오게 하려면

  • 봇카드와 페르소나의 이미지용 외모 태그가 그 인물 구간 맨 앞에 그대로 들어가요.
  • 두 사람이 함께 나오면 |로 나뉜 각자의 구간에 들어가서 특징이 섞이지 않아요. 이때 solo 태그는 자동으로 빠져요.
  • 이미지 연결의 앞에 붙는 프롬프트(Prompt Prefix)는 모든 그림에 들어가요. 장면과 안 맞는 태그가 없는지 확인해요.
비용

다시 그리기는 프롬프트를 새로 쓰느라 텍스트 모델을 한 번 더 불러요. 비용 없이 같은 프롬프트로 다시 뽑고 싶으면 크게 보기의 이 프롬프트로 다시 그리기를 쓰세요.

기억 서재

이야기가 길어지면 AI가 앞부분을 잊어요. 기억 서재 확장이 있으면 지난 이야기를 정리해 두고, 필요한 기억만 꺼내 보내요.

켜는 법

  • 기억 서재 탭 → 이 게임 방을 기억 서재로를 켜요.
  • AI 답변마다 이어서 정리를 켜 두면 답변이 끝날 때마다 새 내용을 정리해요.
  • 쓰는 프롬프트 프리셋에 {{기억}}이 있어야 기억이 실제로 들어가요.

상태 표시

  • 정리 중 · 지금 정리하고 있어요. 몇 번째 묶음인지, 장면으로 묶는 중인지 함께 보여요.
  • 정리 완료 · 정리된 기억 있음 · 몇 번 메시지까지, 장면 몇 개로 정리됐는지 보여요.
  • 정리를 멈췄어요 · 이어서 정리를 누르면 멈춘 곳부터 계속해요.
  • 오류가 생겼어요 · 이유가 함께 나와요. 오래된 메시지를 고치거나 지워서 생긴 오류면 처음부터 다시 정리 버튼이 나와요.

기억 서재가 지난 이야기를 맡으니, 대화 원문은 최근 몇 개만 보내도 흐름이 이어져요.

토큰 아끼기

AI 답변 한 번마다 프롬프트 전체가 모델로 가요. 얼마나 들어가는지 보고 줄일 수 있어요.

토큰 칩

AI 메시지 옆의 13.7k tok 같은 표시를 누르면 프롬프트 구성이 열려요. 어느 부분이 얼마나 차지하는지 검색하면서 볼 수 있어요.

프리셋 부분만 보내기

기본은 자동으로 (문체만)이라 문체 부분과 {{기억}}만 보내요. 프리셋 이름 아래에서 직접 고를 수도 있어요.

최근 대화 수 줄이기

기억 서재를 쓰면 원문을 적게 보내도 돼요. 기억 서재 탭에서 정해요.

규칙은 한 번만

게임 규칙 설명은 프롬프트에 한 번만 들어가요. 따로 할 일은 없어요.

영수증

입력창 옆의 토큰 사용량(tok)을 누르면 영수증이 열려요. 이번 세션에 쓴 토큰과 비용 합계, 최근 호출 20개, 모델 단가 설정이 있어요. AI 메시지의 토큰 칩에서 영수증 보기를 누르면 그 답변 하나의 영수증이 열려요.

영수증에 기록되는 것

  • AI 답변 · 다시 생성 포함
  • 능력치 자동 적용 · 봇카드를 보고 시트 숫자를 자동으로 채우는 호출
  • 수치 제안 · 능력치 자동 적용 중에 한 번 더 부르는 호출
  • 이미지 분석 · 핸드아웃 설명 제안
  • 세션 요약
  • 삽화 프롬프트 · 삽화를 그리거나 그림 위 다시 그리기를 누를 때, 그림용 태그를 쓰는 텍스트 모델의 호출

기록되지 않는 것

  • NovelAI 그림 자체 · NovelAI 구독 포인트(Anlas)로 처리돼서 금액으로 계산할 수 없어요.
  • 기억 서재 정리 · 기억 서재 확장이 자기 연결로 따로 청구해요.
  • 실패한 호출 · 삽화 프롬프트는 썼는데 그림 생성이 실패하면, 그 프롬프트 비용은 기록되지 않아요. 드문 경우예요.

비용은 NanoGPT · OpenRouter · Vertex · LinkAPI 연결이면 가격표에서 단가를 자동으로 가져와요. 다른 연결은 영수증의 모델 단가에서 직접 넣으면 계산돼요. 원화 금액은 영수증의 환율을 정해 두면 함께 보여요.

설치와 업데이트

공유 패키지 marinara-gm-trpg 폴더 하나로 설치하고 지워요. git으로 설치한 Marinara(start.bat으로 실행)에서 써요.

  1. Marinara 끄기

    설치하는 동안에는 Marinara가 꺼져 있어야 해요.

  2. 폴더 넣기

    marinara-gm-trpg 폴더를 통째로 Marinara-Engine 폴더 안에 넣어요.

  3. 설치 실행

    설치.bat을 더블클릭해요. 빌드까지 1~2분 걸려요. [완료]가 나오면 Marinara를 켜요.

Marinara를 업데이트한 뒤

  • 예전 이름(CoC 7th TRPG)으로 설치해 두셨다면 새 폴더의 설치.bat을 실행하세요. 예전 연결을 빼고 새 판으로 바꿔요. 게임 기록은 그대로예요.
  • 게임 메뉴가 안 보이면 Marinara를 끄고 다시 적용.bat을 실행해요.
  • "이 Marinara 버전에는 게임 연결 부분이 맞지 않아요"가 나오면 아무것도 바뀌지 않은 상태예요. 새 버전 패키지를 받아 주세요.

지우기

  • 제거.bat을 실행하면 게임 파일과 연결 부분을 빼고 다시 빌드해요.
  • 게임 기록은 지우지 않고 남겨 둬요.

문제가 생기면

삽화가 "Gallery image prompt compilation failed"로 실패해요

문구의 : 뒤가 실제 이유예요. 대개 삽화 프롬프트를 쓰는 텍스트 모델 쪽 문제(잔액 부족, 서버 오류)예요.

세션·설정 → AI 조사자 설정 → 삽화 프롬프트 모델을 다른 연결로 바꾸거나, 잠시 뒤 다시 눌러 보세요.

그림에 엉뚱한 인물이 나오거나 모습이 섞여요

이미지 연결의 앞에 붙는 프롬프트(Prompt Prefix)를 확인해 보세요. 모든 그림에 들어가는 태그라서, 장면과 맞지 않는 태그가 있으면 계속 영향을 줘요.

이미지용 외모 태그의 가중치 문법(2::태그::)이 깨져 있지 않은지도 확인해 보세요.

AI가 예전 일을 기억하지 못해요

기억 서재 탭에서 이 게임 방이 켜져 있는지, 정리 상태가 완료인지 확인해요.

쓰는 프리셋에 {{기억}}이 들어 있어야 정리한 기억이 프롬프트에 들어가요.

업데이트 뒤 이 게임 대신 일반 게임 화면이 나와요

Marinara를 끄고 다시 적용.bat을 실행하세요. 이미 들어가 있는 부분은 그대로 두고 빠진 부분만 다시 넣어요.

설치 창에 [실패]가 나와요

나온 문구를 그대로 알려 주세요. 바꾸지 않고 상태만 보려면 marinara-gm-trpg 폴더에서 명령 창을 열고 node install.mjs check를 실행하면 돼요.
