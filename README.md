# 마리나라 GM 전용 TRPG

> **베타 (v1.1.34)**: 매일 쓰면서 다듬는 중이에요. 설치하기 전에 Marinara 데이터를 백업해 두세요. 문제가 있으면 이슈로 알려 주세요.

Marinara Engine용 비공식 확장이에요. GM(게임) 모드에 <strong>「마리나라 GM 전용 TRPG」</strong>를 더해요. 크툴루의 부름 7판 규칙과 호환돼요.

> [!IMPORTANT]
> **비공식 · 무료 팬 프로젝트예요.**
> - Marinara Engine(Pasta-Devs)의 공식 기능이 아니에요.
> - 크툴루의 부름(Call of Cthulhu)은 Chaosium Inc.의 상표예요. 이 확장은 Chaosium과 관련이 없고, Chaosium의 허가나 보증을 받지 않았어요.
> - 규칙서 본문은 들어 있지 않아요. 플레이하려면 규칙서를 정식으로 구해 주세요.
> - 돈을 받고 팔거나 유료로 배포할 수 없어요.
> - 권리자가 삭제를 요청하면 바로 내려요. 이슈로 알려 주세요.

## 무엇을 하나요

- **내가 키퍼, AI가 조사자.** 내가 장면을 묘사하고 NPC를 연기하면, AI가 조사자 한 명을 시트대로 연기해요.
- **주사위와 시트는 화면이 챙겨요.** 기능 판정(일반 · 어려움 · 극단, 보너스 · 페널티 주사위), 대성공 · 대실패, 행운 소비, 강행, 이성 판정과 광기, 전투 · 추격, 성장 굴림까지 있어요.
- **기록이 쌓여요.** AI가 알게 된 내용, 조사 노트, 키퍼 비공개 메모, 핸드아웃, NPC, 세션 마무리, 리플레이 내보내기.
- **삽화를 그려요.** 고른 장면으로 그림을 그려 채팅에 붙여요. 봇카드 · 페르소나의 이미지용 외모 태그를 인물마다 그대로 넣어서, 두 사람이 나와도 모습이 섞이지 않아요.
- **기억 서재와 함께 써요.** 기억 서재 확장이 있으면 이 게임 방을 정리해 두고 `{{기억}}`으로 꺼내 써요.

자세한 사용법과 처음 설정 순서는 저장소를 내려받은 뒤 <strong>`설명서.html`</strong>을 더블클릭해서 보세요.

## 준비물

- **Marinara Engine 2.5.2** — git으로 설치하고 `start.bat`으로 켜는 Windows 설치에서 만들고 시험했어요. 다른 판에서는 연결 부분이 맞지 않으면 아무것도 바꾸지 않고 멈춰요.
- **Node.js, git** — Marinara를 설치할 때 함께 깔려 있어요.
- **텍스트 모델 연결** (필수) — AI 조사자가 답할 때 써요. Marinara에 저장된 연결 하나를 골라 써요.
- **이미지 생성 연결** (선택) — 삽화를 그릴 때 써요. 예: NovelAI.
- **기억 서재 확장** (선택) — 긴 이야기를 정리해 두고 AI가 기억하게 해요.

쓰기 전에 Marinara 데이터를 백업해 두세요.

## 설치

### 1. 받기

**방법 A — ZIP으로 받기**

1. 이 페이지 위쪽의 초록색 **Code** → **Download ZIP**을 눌러요.
2. 압축을 풀고, 나온 폴더를 통째로 `Marinara-Engine` 폴더 안에 넣어요.

```
Marinara-Engine\
  ├ start.bat
  ├ packages\
  └ marinara-gm-trpg-main\   ← 여기
```

폴더 이름은 바꿔도 돼요. `Marinara-Engine` 바로 안에만 있으면 돼요.

**방법 B — git으로 받기**

`Marinara-Engine` 폴더에서 명령 창을 열고:

```
git clone https://github.com/T-RPG-GM/marinara-gm-trpg
```

### 2. 설치 실행

1. Marinara를 꺼요.
2. 받은 폴더 안의 <strong>`설치.bat`</strong>을 더블클릭해요. 빌드까지 1~2분 걸려요.
3. <strong>[완료]</strong>가 나오면 Marinara를 켜요.
4. **새 대화 → GM(게임) → 마리나라 GM 전용 TRPG**를 고르면 시작돼요.

설치기가 하는 일은 이것뿐이에요.

1. 게임 파일을 Marinara 폴더에 복사해요.
2. `.git/info/exclude`에 등록해요. `start.bat`은 켤 때마다 새로 생긴 소스 파일을 지우는데, 게임 파일은 지우지 않게 해요.
3. Marinara 파일 몇 곳에 연결 줄을 넣어요(새 대화 메뉴, 채팅 화면, 서버 경로, 삽화 처리). 맞지 않으면 모든 파일을 원래대로 되돌리고 멈춰요.
4. 일부 환경에서 빌드가 멈추는 타입 표기 4곳을 고쳐요(맞을 때만).
5. 화면과 서버를 다시 빌드해요.

게임 기록은 건드리지 않아요.

**예전 이름(CoC 7th TRPG, `marinara-coc7`)으로 설치해 두셨다면** — 새로 받은 폴더의 <strong>`설치.bat`</strong>을 실행하면 예전 연결 줄을 빼고 새 판으로 바꿔요. 게임 기록은 그대로 남아요. 예전 폴더는 지워도 돼요.

**설치 확인** — 바꾸지 않고 상태만 보려면 받은 폴더에서:

```
node install.mjs check
```

## 처음 쓰는 법

새 게임을 만든 뒤 오른쪽 패널에서 차례로 설정해요. 자세한 설명은 `설명서.html`에 있어요.

1. **세션·설정 → AI 조사자 설정**에서 조사자 봇카드, 텍스트 모델 연결, 프롬프트 프리셋을 고르고 **연결 저장**.
2. 같은 화면 프리셋 이름 아래는 <strong>자동으로 (문체만)</strong>을 그대로 두세요. 문체 부분과 `{{기억}}`만 보내서 토큰이 크게 줄어요.
3. (선택) **플레이어 페르소나**를 연결하고, **페르소나 시트** 탭에서 시트를 만들어요. `/check`는 기본으로 이 시트로 굴려요.
4. **조사자 시트** 탭에서 **봇카드 불러오기** 또는 **능력치 자동 적용**으로 시트를 채우고 **생성 확정**.
5. **세션·설정 → 게임 설정**에서 자동 응답, 판정 방식, 행운 소비를 정해요.
6. (선택) **기억 서재** 탭에서 **이 게임 방을 기억 서재로**를 켜요. 프리셋에 `{{기억}}`이 있어야 기억이 들어가요.
7. 입력창에 `/desc 장면 묘사`를 쓰고 **AI 답변**을 눌러요.

### 자주 쓰는 명령어

| 명령어 | 하는 일 |
| --- | --- |
| `/desc 장면` | 장면 묘사 (가운데 정렬) |
| `/as "NPC 이름" 대사` | NPC로 말하기 |
| `/em 행동` | 행동 묘사 |
| `/check 기능명` | 판정 (페르소나 시트). 조사자 시트는 `/check pc 기능명` |
| `/check 기능명 \| hard \| 1` | 어려움 + 보너스 주사위 1개 (`extreme`, `-1`도 돼요) |
| `/roll 1d6` · `/gmroll 1d100` | 공개 · 비공개 주사위 |
| `/toai 지시` · `/w 메모` | AI 전용 지시 · 키퍼 메모 |

## 업데이트

- **Marinara를 업데이트한 뒤** 게임 메뉴가 안 보이면, Marinara를 끄고 <strong>`다시 적용.bat`</strong>을 실행해요. 들어가 있는 부분은 그대로 두고 빠진 부분만 다시 넣어요.
- **새 판을 받을 때** — ZIP은 새로 받아 폴더를 바꾸고, git은 `git pull`을 한 뒤 <strong>`설치.bat`</strong>을 다시 실행해요.
- "이 Marinara 버전에는 게임 연결 부분이 맞지 않아요"가 나오면 아무것도 바뀌지 않은 상태예요. 새 판을 기다려 주세요.

## 비용이 드는 곳

- **AI 답변** — 답변마다 텍스트 모델을 한 번 불러요. AI 메시지 옆 토큰 표시를 누르면 프롬프트의 어느 부분이 얼마나 들어갔는지 볼 수 있어요.
- **능력치 자동 적용, 세션 요약** — 누를 때 한 번씩 불러요.
- **삽화** — 그림용 태그를 쓰는 텍스트 모델 1번 + 이미지 1장. 그림 위 **다시 그리기**도 같아요. 크게 보기의 **이 프롬프트로 다시 그리기**는 이미지만 그려요.
- **기억 서재 정리** — 기억 서재 확장에서 고른 연결로 청구돼요.

**영수증** — 입력창 옆 토큰 사용량(`tok`)을 누르면 이번 세션의 토큰과 비용이 나와요. AI 답변, 능력치 자동 적용, 수치 제안, 이미지 분석, 세션 요약, 삽화 프롬프트가 기록돼요. NovelAI 그림 자체(Anlas로 처리), 기억 서재 정리(그쪽 연결로 청구), 그림 생성이 실패한 삽화의 프롬프트 비용은 기록되지 않아요.

## 끄기 · 지우기

Marinara를 끄고 <strong>`제거.bat`</strong>을 실행하면 게임 파일과 연결 줄을 빼고 다시 빌드해요.

- 게임 기록(Marinara 데이터 폴더의 `coc7-games`)은 지우지 않아요.
- 빌드 호환 수정(타입 표기 4곳)은 빌드가 계속 되도록 남겨 둬요. 기능은 바뀌지 않아요.
- 설치가 거절됐던 상태나 예전 판만 들어가 있는 상태에서도 제거는 돼요.

## 알려진 한계

- Marinara Engine 2.5.2, Windows에서만 시험했어요. Linux · macOS는 `node install.mjs install`로 될 수 있지만 확인하지 않았어요.
- AI는 조사자 한 명을 맡아요.
- 삽화가 어떻게 나오는지는 이미지 모델과 이미지 연결의 Prompt Prefix에 따라 달라요. 모든 그림에 들어가는 태그라서, 장면과 맞지 않는 태그가 있으면 계속 영향을 줘요.
- 파일 이름과 내부 이름의 `coc7`은 예전 판과 게임 기록을 그대로 쓰기 위한 이름이에요.

## 데이터와 보안

- 게임 기록은 Marinara 데이터 폴더의 `coc7-games`에 있어요. 세션·설정의 **캠페인 백업 JSON**으로 따로 내려받을 수 있어요.
- 대화는 설정에서 고른 연결로만 보내요.
- 이 저장소에는 개인 설정, 연결 정보, 게임 기록이 들어 있지 않아요.
